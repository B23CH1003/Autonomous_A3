  {a1, a2}         -> False
  {a2, a3}         -> False

Defended by S?  (book: '{a3, a5} defends a1')
  a1 defended by {a3, a5}   -> True
  a1 defended by {a3}       -> False
  a3 defended by {}         -> True
  a2 defended by {a1}       -> False

Characteristic function F(S)  (book, Example 5.6: F({a3}) = F({a5}) = {a3, a5})
  F({}) = {a3, a5}
  F({a3}) = {a3, a5}
  F({a5}) = {a3, a5}
  F({a3, a5}) = {a1, a3, a5}
  F({a1, a3, a5}) = {a1, a3, a5}

Admissible / complete?  (book, Examples 5.5 and 5.6)
  {}               admissible=True   complete=False
  {a3}             admissible=True   complete=False
  {a5}             admissible=True   complete=False
  {a3, a5}         admissible=True   complete=False
  {a1, a3, a5}     admissible=True   complete=True
  {a1}             admissible=False  complete=False

Grounded extension by iterating F from the empty set  (book, Section 3)
  F^1({}) = {a3, a5}
  F^2({}) = {a1, a3, a5}
  F^3({}) = {a1, a3, a5}
  fixed point reached -> grounded = {a1, a3, a5}

Section D - strategic argumentation (grounded direct mechanism)
========================================================================
Each agent reveals a subset of its arguments; the outcome is the grounded extension of the
graph induced by the union of the revealed arguments; an agent's utility is the number
of its own arguments in the outcome.  Agents are x, y, z.

========================================================================
Example 5.10 / Figure 5.4: hiding an argument is beneficial.  x owns {a1, a4, a5}, y owns {a2}, z owns {a3}; a1 -> a2 -> a3 -> a4, a3 -> a5.
defeats: a1->a2, a2->a3, a3->a4, a3->a5
  agent x owns {a1, a4, a5}
  agent y owns {a2}

    agent z: reveal {a3}  (utility 1; truthful is a best response: True)

  Theorem 5.3 check (truth is a best response against every combination): False
    96 situations examined; agents who can gain by hiding: ['x']
    e.g. agent 0 hides {a1} when agent 1 reveals {a2}; agent 2 reveals {a3}: utility 1 -> 2 (outcome {a1, a3} -> {a2, a4, a5})
  Theorem 5.4 condition (no agent owns two arguments joined by an odd path): False

    - for y and z, revealing their true types weakly dominates revealing nothing

Strategyproof although the Theorem 5.4 condition fails - four instances from the full run:

  instance 9: a direct defeat inside one agent's own arguments (a swap)
    agents own {a1,a2,a3} | {a4,a5,a6} | {};  defeats: a5>a6
    odd paths between one agent's arguments: 1:a5>a6;  strategyproof: True

  instance 30: an odd path of length 3 that only swaps a3 for a1
    agents own {a4} | {a1,a2,a3,a6} | {a5};  defeats: a3>a5 a4>a1 a5>a4

      agent 1 reveals {a2, a3, a6}           -> outcome {a2, a3, a4, a6}           utility 3
    why: a3 -> a5 -> a4 -> a1: a3 accepted <=> a1 defeated, so hiding a3 trades it for a1.

  instance 1098: the odd path ends in a mutual defeat that stays undecided
    agents own {a2,a5} | {a3,a4} | {a1,a6};  defeats: a1>a4 a1>a5 a2>a6 a3>a5 a4>a1 a5>a1

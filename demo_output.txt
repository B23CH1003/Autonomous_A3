  {a3, a5}         -> True
  {a1, a3, a5}     -> True
  {a1, a2}         -> False
  {a2, a3}         -> False

Defended by S?  (book: '{a3, a5} defends a1')
  a1 defended by {a3, a5}   -> True
  a1 defended by {a3}       -> False
  a3 defended by {}         -> True
  a2 defended by {a1}       -> False

Characteristic function F(S)  (book, Example 5.6: F({a3}) = F({a5}) = {a3, a5})
  F({}) = {a3, a5}
  F({a3}) = {a3, a5}
  F({a5}) = {a3, a5}
  F({a3, a5}) = {a1, a3, a5}
  F({a1, a3, a5}) = {a1, a3, a5}

Admissible / complete?  (book, Examples 5.5 and 5.6)
  {}               admissible=True   complete=False
  {a3}             admissible=True   complete=False
  {a5}             admissible=True   complete=False
  {a3, a5}         admissible=True   complete=False
  {a1, a3, a5}     admissible=True   complete=True
  {a1}             admissible=False  complete=False

Grounded extension by iterating F from the empty set  (book, Section 3)
  F^1({}) = {a3, a5}
  F^2({}) = {a1, a3, a5}
  F^3({}) = {a1, a3, a5}
  fixed point reached -> grounded = {a1, a3, a5}
